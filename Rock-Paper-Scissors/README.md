# Rock Paper Scissors

A simple command-line Rock Paper Scissors game written in Python.

## Description

Play Rock Paper Scissors against the computer. The game continues until you type `quit`.

## Features

- Classic Rock Paper Scissors gameplay
- Random computer opponent
- Input validation
- Continuous play until the user quits

## Requirements

- Python 3.x

## How to Run

1. Save the code as `rps.py`
2. Open a terminal in the same folder
3. Run the game:

```bash
python rps.py
```

## How to Play

1. When prompted, type one of the following:
   - `rock`
   - `paper`
   - `scissors`
2. The computer will randomly choose its move
3. The winner is announced
4. Type `quit` anytime to exit the game

## Example

```
=== Rock Paper Scissors ===
Type 'rock', 'paper', or 'scissors' (or 'quit' to exit)

Your choice: rock
Computer chose: scissors
You win!

Your choice: paper
Computer chose: paper
It's a tie!

Your choice: quit
Thanks for playing!
```
